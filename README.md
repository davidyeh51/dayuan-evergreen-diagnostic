  - **歷史累計短發高達 12.1 萬度**：Inv5 累積發電量僅 **378,958 kWh**，相較正常機台（約 50 萬度）累計短少達 **121,335 kWh**，資產歷史減損超過 **NT$ 60 萬元**！急需陽光電源（Sungrow）原廠進場出保換板。
