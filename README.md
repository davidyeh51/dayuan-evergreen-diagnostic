## 📌 核心診斷重點與事實（Core Diagnosis Facts）

- **分析數據規模**：2025/09/22 – 2026/09/21 共 364 天完整年度高精度 SCADA 遙測日誌，17 台在線逆變器全量採集（全場累計發電量 **2,213,048 kWh**，售電收益 **NT$ 10,976,720**，躉購單價 **NT$ 4.9600/kWh**）。
- **👑 全場標竿機台 (Benchmark)**：**Inv7**（年度等價時數 Ey = **1,161.33 h**，平均 PR 達 80.5%）。
- **🟢 P1 Inv6 化學性漏電 ＆ 奈米材料改善成效實證**：
  - 改善前（2025/10 ~ 2026/04 東北季風與梅雨季反潮期間）：發生嚴重的「清晨反潮化學性漏電」，單日發電比值曾暴跌至 18% ~ 45%（如 2025/11/24 比值僅 0.186、2026/04/14 僅 0.256）。改善前平均比值僅 0.92 ~ 0.95。
  - 改善工程（2026/04/14 ~ 04/16）：施作「奈米超晶體 / 高分子絕緣材料」表面修復處理，消除化學性漏電並降低線路阻抗。
  - 改善後驗證（2026/05 ~ 09）：即便經歷連續梅雨與夏季雷雨高濕，化學性漏電徹底消失；5 月中旬後相對 Inv1 比值攀升至 **99% ~ 102%**（2026/07 比值 1.001、08月 1.007、09月 1.011），同時降低線路阻抗推升發電效率！
- **🔴 P1 Inv5 非預期跳脫停機**：
  - 年度等價時數僅 **1,045.10 h**（全場倒數第一，相對標竿僅 89.99%）。
  - 短少發電度數高達 **13,387 kWh**，單台年度財務損失 **NT$ 66,397**。
  - 遙測特徵：2025/11/20~11/26 連續 6 天發電歸零（0 kWh）；2026/08/31~09/07 再度停機跳脫 4+ 天，屬 AC 併網斷路器或控制板異常，急需排查復歸。
- **🟡 結構與環境共構根因 (對接現場調查報告書)**：
  - 外圍鋼構經雨水天然沖洗無鹽害，但**內部死角鋼構鹽害嚴重沉積生鏽**，且 C 鋼有積水情況。
  - 沿海鹽霧沉積於接頭與邊框是誘發化學性漏電與結構腐蝕的共構環境根因。
- **💰 全場年化損益與 20 年現金流增益**：
  - 相較標竿全場 17 台年化總短少度數為 **58,770 kWh/年**，年化營收短收 **NT$ 291,497 / 年**。
  - 全場全面導入奈米防護塗層、鋼構除鏽防蝕與 SCADA 動態差分告警後，20 年累計折現現金流增益達 **NT$ 408.5 萬元**，專案 IRR 推升 **+0.65%**！
